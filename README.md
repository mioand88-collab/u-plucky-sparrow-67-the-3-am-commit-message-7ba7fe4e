## What it does

`main.ts` writes one commit message to `/output/entry.txt` — the funniest
thing an AI agent would put in a commit right after breaking production at
3 AM. The message is a single line of at most 200 characters.

Run it with Node 22 or later:

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written.
